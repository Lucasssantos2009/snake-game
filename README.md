# 🐍 Snake Game

Um clássico jogo da **Cobrinha (Snake)** desenvolvido com **HTML, CSS e JavaScript puro**.
O projeto foi criado para rodar diretamente no navegador, sem necessidade de instalação ou dependências externas.

## 🎮 Sobre o Projeto

Este projeto recria a experiência do tradicional jogo Snake, onde o jogador controla uma cobrinha que deve comer frutas 🍎 para crescer e aumentar sua pontuação.

O objetivo é conseguir a maior pontuação possível sem colidir com as paredes ou com o próprio corpo da cobrinha.

## ✨ Funcionalidades

✅ Movimentação utilizando as setas do teclado ⬆️⬇️⬅️➡️
✅ Sistema de pontuação 🏆
✅ Frutas aleatórias 🍎
✅ Crescimento da cobrinha ao coletar frutas 🐍
✅ Detecção de colisão 💥
✅ Tela de Game Over 🚨
✅ Botão para reiniciar o jogo 🔄
✅ Interface simples e responsiva 📱
✅ Executa diretamente no navegador 🌐

## 🛠️ Tecnologias Utilizadas

* 🟧 **HTML5** — Estrutura da aplicação
* 🎨 **CSS3** — Estilização e layout
* ⚡ **JavaScript** — Lógica do jogo e movimentação

## 🚀 Como Executar

1. Clone este repositório:

```bash
git clone https://github.com/seu-usuario/snake-game.git
```

2. Acesse a pasta do projeto:

```bash
cd snake-game
```

3. Abra o arquivo:

```
index.html
```

4. Divirta-se jogando! 🎮🐍

## 🎯 Como Jogar

Use as teclas:

⬆️ Cima
⬇️ Baixo
⬅️ Esquerda
➡️ Direita

Colete as frutas 🍎 para aumentar sua pontuação.

⚠️ Evite:

* Bater nas paredes 🧱
* Colidir com o próprio corpo 🐍
